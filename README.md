# 人口密度ヒートコロプレスマップ（都道府県）

日本の都道府県人口密度データをSVGコロプレス地図で表示。クリックで詳細情報を表示するインタラクティブマップ。

## 機能

- 47都道府県の人口密度データをハードコード（人口・面積・密度）
- 格子グリッドで日本地図を近似表現（11×11グリッド）
- 密度別の色グラデーション（白→赤の5段階：<100/100-299/300-599/600-999/1000+）
- クリックで都道府県名・人口・面積・密度・ランクをポップアップ表示
- 人口密度上位10都道府県のランキングリスト（クリックで詳細表示）
- キーボード操作対応（Tab + Enter/Space）

## 技術仕様

- 外部SVG地図データ不使用（CSSグリッドで近似配置）
- 人口データ出典：総務省統計局（2020年国勢調査ベース概算値）
- バニラJS / Tailwind CDN のみ
